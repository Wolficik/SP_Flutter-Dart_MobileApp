# Mini Katalog Uygulaması

## Kısa Açıklama
Flutter temel widget'ları, navigasyon yapısı ve state yönetimi kullanılarak geliştirilmiş; Ürün listeleme, ürün detay sayfası ve basit sepet simülasyonu içeren e-ticaret arayüzü uygulamasıdır.

## Kullanılan Sürüm
Flutter 3.44.0 || Tools • Dart 3.12.0 • DevTools 2.57.0

## Çalıştırma Adımları

1. `flutter pub get` (Gerekli paketleri yükler)
2. `flutter run` (Uygulamayı bağlı olan emülatörde veya fiziksel cihazda başlatır)
